# clank-anki
Anki, but with the clanks


General outline of structure:
1. Front-end in some language. Idk what language. I guess Rust should be fine, since Haganta's in the rust mode. 
2. Main Engine in Rust. It's just spaced repetition, so nothing fancy, and easy enough to do.
3. A kind of structure to store cards in. I guess we can go with the good-ol json.
4. We can consider some kind of cloud hosting, so we can access from the phone, you know, use it on da go. 
5. We need to figure out where to store API keys and whatnot. I think we can use something like Deepseek, since they have uber cheap tokens.
